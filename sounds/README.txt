Este directorio contiene los archivos de sonido necesarios para el juego.

Archivos requeridos:
- acierto.mp3: Sonido para respuesta correcta
- errado.mp3: Sonido para respuesta incorrecta
- despliegue_opciones.mp3: Sonido al mostrar las opciones
- warning.mp3: Sonido de advertencia (últimos 5 segundos)
- level_up.mp3: Sonido al subir de nivel
- background_music.mp3: Música de fondo

Nota: Si los archivos no están presentes, el juego funcionará sin sonidos.

Archivos de sonido necesarios:

1. correct.wav - Sonido para respuestas correctas
2. wrong.wav - Sonido para respuestas incorrectas
3. level_up.wav - Sonido para subir de nivel
4. background_music.mp3 - Música de fondo

Nota: Estos archivos deben ser proporcionados por el usuario. Los archivos deben ser:
- Archivos WAV para efectos de sonido
- Archivo MP3 para la música de fondo
- Duración corta para los efectos (menos de 1 segundo)
- Volumen moderado
